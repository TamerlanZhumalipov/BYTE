# ENT-2026 mapping

Apply `python manage.py migrate`. Migration 0005 creates the bilingual informatics
catalogue and maps existing root Sections by exact slug, then normalized exact
RU/KZ title. Ambiguous title matches and children are skipped. Existing learning
path, quizzes, analytics and AI code are not changed.

For a fresh database whose course materials are loaded later:

```
python manage.py seed_materials
python manage.py seed_ent_specification --map-existing
```

`seed_ent_specification` alone creates missing catalogue entries and preserves
existing topic edits, including removed mappings. `--map-existing` explicitly
adds initial mappings back, without deleting custom ones or changing titles.
Review mappings and coverage notes in admin → Темы ЕНТ. The specification screen
links to each topic; the topic screen has a searchable dual-list root selector.

## Forecast contract

Authenticated GET `/api/ent/specifications/2026/?language=ru` returns specification
metadata and ordered topics with bilingual titles, localized titles, coverage
notes and published root section IDs/slugs. `kk` and `kz` select Kazakh; otherwise
the session language applies. Invalid language returns 400, missing year 404,
other methods 405 (after authentication). The API exposes no lesson content,
answers or student records and does not grant access to locked lessons.

`core.ent.get_ent_catalogue(year=2026, subject="informatics", language="ru")`
provides the same data without an HTTP dependency, in three database queries.
For future evidence aggregation, root links include their descendants conceptually;
expand and deduplicate IDs before aggregating. Shared roots (Python, hardware,
SQL) must not be double-counted. Contest accounts currently have no link to site
users; no contest mastery is inferred here. There is no stored lesson-completion
signal in the current model. Official specification does not assign fixed marks
per topic, so this change creates no such allocation or forecast.
