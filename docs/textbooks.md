# Проверенные учебники BYTE

После обновления выполнить `python manage.py migrate` и перезапустить Django.
Миграции 0007–0008 создают каталог и добавляют «Информатика», 8 класс,
С. Т. Мухамбетжанова, А. С. Тен, Л. Г. Демидова, Атамұра, 2021,
ISBN 978-601-331-945-2, язык kk, и 18 параграфов.

Источник: предоставленный владельцем 952.pdf, титул/выходные данные с. 1–2,
оглавление с. 3–4. Подтверждены начальные печатные страницы параграфов;
полные диапазоны и PDF-страницы не утверждаются. Номер издания не указан.
Сам PDF не копируется в репозиторий и не публикуется.

В /admin/ доступны «Учебники» и «Ссылки на параграфы». На карточке ссылки
можно выбрать разделы BYTE и темы ЕНТ, изменить ключевые слова RU/KZ,
указать основание проверки и включить флаг «Ссылка проверена».
Для нового издания создайте отдельный учебник. Снятие флага проверки или
отключение книги немедленно исключает её из рекомендаций.
Связи с BYTE заполняются по существующим корневым slug; если разделы созданы
позднее, привяжите их в админке. Привязки к 13 темам ЕНТ независимы от этого.

Forecast показывает до двух параграфов под каждой из трёх рекомендаций.
API /api/ent/forecast/ содержит их в recommendations[].reading. Это
дополнительный материал по части темы, не заявление о полном её покрытии;
формула балла не меняется. Приоритет у языка интерфейса; иной язык явно указан.

В чате запросите «Какой учебник почитать про while?» или
«while туралы қай кітап оқу керек?». Такие ответы формируются сервером
по проверенному каталогу, без Gemini. Обычный чат продолжает работать через
Gemini, а его инструкции запрещают выдумывать библиографию. Показ самого
виджета по-прежнему зависит от существующей настройки BYTE AI.
Поиск — по заданным ключевым словам, не полнотекстовый поиск/OCR.
Для «учебник по этой теме» используются привязки текущего раздела и родителей.
При отсутствии совпадения предлагается уточнить тему; случайные страницы
не подставляются. Выбор личного учебника ученика пока не реализован.

Проверки: `python manage.py test core.tests`, `python manage.py check`,
`python manage.py makemigrations --check --dry-run`.
