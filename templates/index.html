01 · основной язык

Python

Синтаксис, циклы, функции, работа со списками и строками — основа большинства заданий ЕНТ.

SQL

C++

HTML

05 · стили

CSS

Оформление, адаптивность, сетки — доводим страницы на HTML до законченного вида.
